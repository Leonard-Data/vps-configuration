# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Delegated through “just get going”: plain local HTML, shared CSS and small JavaScript; no dependencies required to read.

## Users
A new VPS owner learning deployment, control, monitoring and infrastructure playbooks. Beginner level is an explicit teaching assumption, not assessed knowledge.

## Product Purpose
A source-backed learning workspace that connects VPS concepts to safe operational practice.

## Operating Context
Hostinger VPS support is the requested provider reference. The learner reads locally, may print references, and returns across sessions.

## Capabilities and Constraints
Cover security, backup, operating systems, Docker Manager, DNS, APIs, deployment and monitoring. Start with a short mental-model lesson, then provide a broader reference and staged playbook. Never change the actual VPS. No OS, domain, installed software, access rights or backup entitlement has been verified.

## Product Principles
- Distinguish conceptual explanation from instructions to execute.
- Cite primary documentation and warn before destructive actions.
- Use retrieval practice; do not claim mastery without evidence.
- Keep content readable offline and printable; external sources need internet access.
