Your learning roadmap

Start with safe access, then choose Hermes or the separate Pi factory track. Neither agent requires the other. Lesson 4 adds an independent n8n workflow lab. Lessons 5–7 connect the services through manual version maintenance, approved CI/CD and recovery. The automation labs are optional; completion is something you demonstrate, not something this page tracks.

Start small. Build a reliable habit.

  1. Trace one request through your VPS

    A short first lesson. Connect DNS, the operating system, Docker and your application. Then test your mental model.

    About 8 minutes · no server access needed
  2. Set up Hermes Agent safely

    Learn the Windows → VPS → GitHub boundaries, then follow a staged Ubuntu 24.04 setup with an optional CI/CD lab.

    Short lesson + hands-on playbook · separate steps, not one giant script
  3. Run Pi as a software factory

    Learn the coordinator, crew, terminal and worktree roles, then install through explicit safety gates.

    Short lesson + printable installation playbook · you run the commands
  4. Understand n8n on your VPS

    Compare install options, build one harmless workflow and distinguish persistence from recoverability.

    Short lesson + staged n8n setup playbook · no live server changes
  5. Maintain your services, one change at a time

    Manual setup and version checks → approval-gated CI/CD → coherent recovery.

    Lessons 5–7 · manual, CI/CD and recovery playbooks
  6. Keep the VPS field guide nearby

    Security, OS choices, Docker Manager, DNS, APIs, monitoring and recovery—in one printable reference.

    Look things up · do not memorize everything at once
  7. Rehearse the infrastructure playbook

    Work through safe gates from inventory to deployment and restore testing. Each stage says what evidence to collect.

    A planning checklist · not a script to run blindly

The mission

Operate your own VPS confidently: deploy, control, monitor and recover it using a repeatable playbook.

Beginner level is our starting assumption. You reported Ubuntu 24.04 LTS and selected Windows for Lesson 2. The live OS, template and backup plan have not been checked.

Nothing here connects to your VPS. Quiz answers stay in this page session; no credentials are requested.

One thing to remember today

A running container is not the same as a healthy application. A stored volume is not the same as a backup. An open port is not the same as a secure service.

Learn now. Retrieve later.

After the first lesson, close it and explain the request path from memory. Try again tomorrow, then in a week. Ask your teaching agent about anything unclear, or share your answers for feedback.
